\section{Resumen}

En el presente documento se desarrolla el proyecto de finalización de carrera \enquote{Control de acceso para institución educativa}, el cual implementa un sistema de gestión y registro de ingresos. El sistema permite el acceso regular del personal autorizado mediante credenciales basadas en tecnología NFC (\textit{Near Field Communication}) y la validación remota de visitantes externos por parte de un operador humano, utilizando el reconocimiento visual a partir de fotografías recibidas en un dispositivo móvil.
